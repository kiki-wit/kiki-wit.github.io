# 🔍 Kafka의 기본 개념

Apache Kafka는 고성능 분산 이벤트 스트리밍 플랫폼으로, 실시간 데이터 파이프라인과 스트리밍 애플리케이션을 구축하는 데 사용된다. <br/>
스트리밍이란 데이터가 실시간으로 흘러들어오는 형태를 의미하며, 유튜브 영상, 주식 시세 확인 등에 쓰일 수 있다. <br/>
스트리밍 플랫폼은 이런 데이터가 흐르는 파이프라인을 만들어주는 시스템이라고 볼 수 있다. <br/>

# 🔍 쿠버네티스(k8s)의 기본 개념

쿠버네티스는 컨테이너로 만들어진 애플리케이션과 워크로드를 효율적으로 관리하기 위한 오픈소스 플랫폼이다. 어디서나 실행할 수 있고(이식성), 필요할 때 규모를 늘리거나 줄일 수 있으며(확장성), 정해진 규칙(선언적)에 따라 자동으로 관리 할 수 있다.

> 컨테이너(Container): 애플리케이션과 실행 환경을 함께 묶어, 운영체제에 종속되지 않고 어디서든 동일하게 실행할 수 있는 격리된 공간


**예시**
- 일반 실행: 내 PC에 Python 버전 3.9 설치해서 프로그램 실행 → 서버에 가보니 Python 3.6이라 안 됨 😓
- 컨테이너 실행: “Python 3.9 + 내 코드 + 필요한 라이브러리”를 하나로 묶은 Docker 이미지 생성 → 어디서 실행해도 동일한 결과 ✅


### 쿠버네티스 클러스터

>클러스터: 여러 대의 컴퓨터(서버)를 하나로 묶어서 하나의 컴퓨터처럼 사용하는 것

쿠버네티스의 클러스터는 컨트롤 플레인 컴포넌트과 노드 컴포넌트로 이루어져 있다. 이 클러스터 위에서 애플리케이션이 배포되고 관리된다.
컨트롤 플레인 컴포넌트는 전체 상태를 관리하고 노드 컴포넌트는 각각의 서버 역할을 하고 API Server와 통신한다.

### 컨트롤 플레인 컴포넌트

- API Server : 전체 서버를 관리하는 중추
- etcd : 키-값 저장소로 데이터베이스 역할을 한다.
- Scheduler : pod을 할당하여 자리배치 시킨다.
- Controller Manager : 서버 가용/확장성 등 컨트롤러 통합 관리

### 노드(서버) 컴포넌트

- kubelet : 각 노트(서버)에 깔려있는 에이전트 프로그램으로 API Server와 통신한다.
- kube-proxy : 네트워크 담당
- Container Runtime : 컨테이너 실행 엔진
